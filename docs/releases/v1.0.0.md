# Release `v1.0.0` (`2026-11-21`)

**Waveshare ESP32-S3 RLCD MultiBoot Loader `v1.0.0`** is the initial public release of the autonomous Dual-OTA firmware loader and web configurator tailored specifically for the **Waveshare / Luckfox ESP32-S3 4.2″ Reflective LCD (RLCD)** development board.

---

## Highlights & Capabilities

### 1. Dual-OTA Partition Architecture & Reset Safety
- **Permanent Launcher Anchor:** Resides in partition `app0` (`0x10000`, 3.5 MB), ensuring that the boot manager can never be overwritten by guest applications.
- **Dynamic Application Flashing:** On-demand flashing of firmware binaries stored on the MicroSD card (`/firmware/*.bin`) into partition `app1` (`0x390000`, 3.5 MB).
- **Zero-Second Fast Boot:** If the selected application is already flashed in `app1`, it launches immediately with zero flash wear or delay.
- **Guaranteed Launcher Return:** Compliant application modules reset the OTA boot pointer to `app0` during their startup, guaranteeing that physical resets, power-cycles, or crashes return to the MultiBoot Loader.

### 2. Modern RLCD Display Engine & Typography
- **ST7305 Native Driver:** Optimized 1-bit monochrome `400×300` SPI driver utilizing U8g2 (`U8G2_R1` landscape).
- **Negative Top Header Bar:** 24 px inverted status bar displaying Wi-Fi connection state, current IP address, and battery telemetry.
- **Negative Battery Indicator:** Double-outlined battery frame with dynamic filling, displaying both raw voltage (e.g. `4.12V`) and calculated percentage.
- **Unified Technical Splash Screen:** Distinctive silicon package emblem with corner brackets, board specifications, and a dynamic progress bar for cold boot and flashing transitions.

### 3. Persistent UI Reordering & Web Manager
- **Custom Firmware Priority:** Up/Down controls (`▲`/`▼`) in the Web Manager allowing users to order firmware slots according to their preferences.
- **NVS Persistence:** Custom order is stored in non-volatile storage (`"launcher"` / `"fw_order"`) and loaded automatically on boot.
- **Web Device Hub:** Embedded HTTP server accessible over local network:
  - One-click application launch and flash triggers.
  - Direct upload of `.bin` firmware files to `/firmware/`.
  - Game Boy ROM (`.gb` / `.gbc`) upload to `/roms/`.
  - Wi-Fi network configuration with AP fallback.

### 4. Hardware Interfacing & Serial CLI
- **Physical Controls:** Intuitive two-button navigation: `[KEY]` cycles through firmware entries; `[BOOT]` executes launch/flash.
- **High-Speed SDMMC:** 1-bit SDMMC bus clocked at 40 MHz for maximum file transfer and streaming throughput.
- **USB-CDC Console Interface (115200 baud):**
  - `STATUS`: Reports current launcher state, battery status, active app, and IP.
  - `BOOT <filename.bin>`: Triggers flash/boot sequence over serial.
  - `SDLIST`: Lists all firmware files and ROMs on MicroSD.
  - `SDPUT <path> <size>`: Direct binary file upload to MicroSD with CRC32 verification.
  - `BATTERY`: Reports filtered voltage and battery level.

## Flashing Instructions

### Option A: Automated Windows Script (Recommended)
Download the release assets, connect your board over USB, and run:
```powershell
.\release\flash.ps1 -Port COM11
```
Or double-click `release\flash.bat` and enter your COM port.

### Option B: Unified Factory Flash (`0x0`, 16 MB Image)
For a fresh, unpartitioned ESP32-S3 board:
```sh
python -m esptool --chip esp32s3 --port COM11 --baud 921600 \
  --before default-reset --after watchdog-reset write_flash \
  --flash_mode qio --flash_size 16MB --flash_freq 80m \
  0x0 waveshare-esp32s3-rlcd-multiboot-loader-full-16MB-v1.0.0.bin
```

## Package Integrity Manifest
Checksums for every binary and script are documented in `SHA256SUMS.txt`:
- `waveshare-esp32s3-rlcd-multiboot-loader-full-16MB-v1.0.0.bin` — Complete 16 MB factory image (`0x0`).
- `rlcd-launcher-v1.0.0.bin` — Standalone MultiBoot Loader application binary (`0x10000` / app0).
- `bootloader.bin`, `partitions.bin`, `otadata.bin` — System partition components.
- `flash.ps1`, `flash.bat` — Standalone Windows flash scripts.
- `SHA256SUMS.txt` — Cryptographic SHA-256 verification manifest.
